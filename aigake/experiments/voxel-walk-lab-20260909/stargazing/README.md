# 星見の丘・星座観測

天の川を見渡す天球上で88星座を探して線で結ぶ。正解した星座は端末の星座帳に一度だけ登録。繰り返し遊べる。回数制限・追加API料金なし。

## 星空の描画

- 天の川を画像なしで描画。銀河座標に沿う光の帯・暗黒帯・11万個の星粒を手続き的に生成し、d3-celestialの5,044個の実在恒星を重ねる。全レイヤーを同じ日時・地点で地平座標へ変換する。背景を固定したまま星座だけを動かさない。
- フルスクリーンのWebGL描画。星の等級・B-V色指数を使った光芒、控えめなまたたき、空気の明るさ、架空の丘。眺めるための明るさ・色調で、肉眼の見え方を定量再現するものではない。
- 初期視点は、その日時に地平線上にある天の川の方向。「今夜の星座」は構成星すべてが高度5度以上の星座だけ。短い形のヒント、方角と高度、視点移動、実際の星の位置での線つなぎ。
- ドラッグ・ピンチ・ホイール・矢印キーで操作。星を結ぶときだけ番号を表示。お手本は折りたたみ、任意で空へ重ねる。星座帳を開く・観測を閉じると描画を停止。30fps、端末の描画倍率は最大1.75。動きを減らす設定ではまたたきと視点移動アニメーションを止める。
- 天の川は `milky-way.mjs` の多層ノイズと決定的な粒子分布。帯の向きは銀河座標に従うが、細かな星粒・光・塵の形は鑑賞用の生成表現で、実在する暗黒星雲や微光星を個々に再現するものではない。
- 光の層は最大100万画素のGPU描画結果を一時保存し、視点・画角・日時・地点・画面サイズが変わったときだけ再計算。星粒と恒星は描画ごとに投影する。天の川全体を動かすアニメーションは加えない。
- iOSビルドは天の川の画像を同梱しない。恒星表・描画コード・ライセンスを同梱し、描画時に外部APIやCDNへ接続しない。
- 恒星表の再コンパイルは `node compile-stars.mjs`。現行の座標資料と出典は `data/SKY-SOURCES.txt`。以前のNASA背景・`prepare-sky.py`・`assets/CREDITS.txt`は開発資料として残すが、現行描画・iOSビルドには使わない。

- `town-studio`：星見の丘の4棟が20,000歩へ到達すると解放。完成形プレビュー・建築再生は解放しない。増築は条件に含めない。
- `/walk/`：星見の丘の地区全体の建築完了、または完成済み地区のアルバムがあると解放。次の地域へ移っても利用できる。
- 単独の `stargazing/` とスタジオの「体験する」は体験用。日付を変えて季節を試せる。正式な星座帳・歩数台帳には書き込まない。
- 正式モードは端末の当日。夜の20〜23時または当日の未明0〜4時を選ぶ。昼間でも遊べる。日付をまたいだ正解判定では空を更新して再選択する。
- 北緯35°／南緯35°、東経135°、UTC+9の仮想地点。GPS不要。両地点を行き来して88種類を収集する。
- 星の赤経・赤緯、日付、恒星時から高度を計算。構成星がすべて高度5°以上の星座を表示。歳差・固有運動・大気差・日出入・月明かり・天候・地形は省略したゲーム用近似。
- 星座帳に登録日・観測日時・地点を保存。未観測の星座は見える月を表示。端末内保存のみ。壊れたデータは上書きしない。
- タップ2回で線をつなぐ。同じ線を再選択すると削除。順番・線の方向は不問。枝分かれ・複数の独立した図にも対応。拡大・ドラッグ、お手本の重ね表示、番号指定、戻す・消す・ヒントを用意。

## データと検証

`data/constellations.lines.json` と `data/constellations.json` は [d3-celestial](https://github.com/ofrohn/d3-celestial) から2026-09-20取得。Copyright (c) 2015 Olaf Frohn, BSD-3-Clause。ライセンス同梱・ゲーム内から表示可能。

`node compile-data.mjs` で `catalog.mjs` を再作成。元資料の89図のうち、へび座の頭部・尾部を1星座に統合。資料の実際の座標・星座線を使う。IAUが定めるのは星座の領域で、線の引き方は公式に一意ではない。この資料の結び方をゲームの正解とする。

参照：[国立天文台](https://www.nao.ac.jp/news/blog/2022/20220809-constellation.html)、[USNO恒星時](https://aa.usno.navy.mil/faq/GAST)、[USNO地平座標](https://aa.usno.navy.mil/faq/alt_az)。

`node --test model.test.mjs`：88種類、へび座、座標と線、投影、季節、両地点での全88到達性、正誤、未解放、重複登録、破損保存、完成境界。iOS用 `build-walk.mjs` にデータ・CSS・説明ページ・ライセンスを含める。
