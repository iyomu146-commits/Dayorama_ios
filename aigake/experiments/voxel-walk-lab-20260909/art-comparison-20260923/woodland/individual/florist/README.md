# 花屋の個別試作

採用全景 `town-voxel-v2.png` の矩形 `[267,410,453,310]` を実際に切り出した画像を正本として、花屋を独立制作した。元画像との画素一致とハッシュは `evidence/crop-verified.json`。別の建物テンプレートを使わず、寸法・開口・ガラスの張り出し・花箱をこの画像から設計した。描画、外面生成、材質の数学、検査の基盤は共用。

## florist1 / 2026-09-24

- **全セル15cm角、15,761セル、15,642三角形、35部品**。
- 緑の切妻屋根、黄土色の壁、左のガラス張りの張り出し、正面陳列窓、右の入口を分けて制作。参照にない煙突や街灯は追加しない。
- 屋根は2列＋色違い2列＋控えめな継ぎ目1列。継ぎ目もセルで埋め、屋根の下地を連続させる。
- 壁は数セルのまとまりで濃淡を付ける。木には向きを分けた木目、瓦には控えめな斑、素材別の粗さと法線変化を使用。頂点やセルの寸法は変更しない。
- 21株の花。桃色・黄色・白・紫・橙の花弁と、金色またはクリーム色の中心、緑の茎と葉を分ける。株同士のセル上書きを禁止し、各花箱または窓台に支持させる。
- ガラスは不透明な色付きボクセル。窓中央の縦枠は省略。入口の正面を空け、鉢や花箱の地面を揃える。

## 検証と限界

`check-model.mjs` は接地、建築段階ごとの支持、屋根被覆、入口、窓、花の支持、保存復元を検査する。`check-boundary.mjs` は実ブラウザーの三角形を18,756のセル外面と全数照合。正面・左右・裏・参照方向、白い光・横からの光、300px表示を確認した。

全体の色判定と部品ごとの可視画素による判定を両方保存。汎用の頂点レイ検査は不合格が残るため、格子専用の全数照合と区別して報告する。詳しくは [検証の範囲](validation-scope.md)。エージェントの視覚評価はユーザーの採用判断と別。

元画像のふっくらした花弁、角の丸み、不規則な瓦、透明な室内は近似。参照に写らない裏面は閉じた単純な壁として推定した。地区全景、歩数進行、昼夜の演出への統合とiPhone実機性能の計測は未実施。

Pixelationはオフ。弱設定の採用判断は全景完成後に行う。単体版で回転・分解・部品選択・ボクセルJSON保存ができる。検査用Pythonはローカルのimg2threejsに依存し、プレビュー実行には不要。
