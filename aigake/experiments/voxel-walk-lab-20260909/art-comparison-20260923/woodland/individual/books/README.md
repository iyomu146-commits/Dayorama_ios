# 本屋の個別試作

採用全景 `town-voxel-v2.png` の本屋を、矩形 `[978,125,396,374]` で切り出した実画像を正本にした。元画像とのRGB画素一致とハッシュを再検証済み（`evidence/crop-verified.json`）。新しい建物画像を生成したり、喫茶店の建物テンプレートを流用したものではない。共用したのは整数セルの表面生成、材質処理の数学、表示・検査の基盤。

## books1 / 2026-09-24

- 全セル15cm角。**16,671セル、15,480三角形、27部品**。
- 紫灰色の寄棟屋根、青灰色の石壁、2段の本棚が見える窓、右側の入口とベンチを個別設計。
- 瓦の色は「2セル＋色違い2セル＋継ぎ目1セル」。寄棟の各斜面で向きを変え、下地を連続させる。継ぎ目に穴や深い溝を作らない。
- 石の色は2セル高・4セル幅を目安に目地をずらしたまとまりで変える。青・灰・少量の暖色を混ぜ、ランダムな1セルノイズを避ける。
- 窓中央の縦枠を省略。ガラスは従来どおり、不透明の色付きセルによる表現。本は棚・窓台で支持し、鉢と植物は接地したセルでつなぐ。
- 木目、粗さ、小さな法線変化は材質ごとに付ける。頂点位置やセルの寸法は変えない。喫茶店固有の瓦座標判定は使わない。
- 裏面と内部は参照に写らないため、単純な閉じた石壁として推定。

## 検証

`check-model.mjs` で整数座標、全セルの接地連結、屋根の被覆、開いた煙突と底、入口の空き、窓の縦枠、本の支持、ベンチ4脚、部品・保存復元を検査。`runtime.test.mjs` はJSONの往復と不正値拒否、分解時の内部面復元、各建築段階の接地、実ブラウザーの27部品と接続点を確認する。

実ブラウザーの外面は、占有セル境界の向き・面積と全数照合。正面・左右・裏・参照方向、白い光・横からの光、264px表示、390px幅のレイアウトを確認した。通常表示は操作時のみ描画し、影も光や組み立て位置が変わったときに更新する。検証時の組み立て表示は、影受けを含め28描画呼び出し。iPhoneの実機性能は未測定。

汎用の頂点レイ検査には不合格が残る。格子形状向けに、セルの外面との全数一致を構造の検証とした。全体の代表色による検査と部品の実可視画素による検査も両方保存する。詳細は [検証の範囲](validation-scope.md)。汎用検査すべてに合格したという意味ではない。

## 残る差と次の作業

元画像の角の丸み、瓦の不揃いさ、本の斜め置きや細かな背表紙は近似にとどまる。15cmグリッドで編集できることを維持している。視覚レビューはエージェントの判断であり、ユーザーによる採用判断とは別。

地区全景・歩数進行・昼夜の生活演出への組み込みは未実施。単体版で分解とボクセルJSON保存を確認できる。Pixelationはオフ。ユーザーの方針に従い、弱設定の採用判断は全景完成後に行う。

検証画像・診断・元の不合格を `evidence/` に保持。作業用の再分割境界データは実ブラウザー形状から再生成できるため、GitHub書き出し時だけ省略する。検証用Pythonはローカルのimg2threejsに依存するが、プレビューには不要。
