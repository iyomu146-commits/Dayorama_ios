# 住宅の個別試作

全景 `town-voxel-v2.png` の住宅を、画素を変更せず切り出した `../../references/crops/home.png` から独立して組み立てた。喫茶店の寸法・建物テンプレートは使用していない。共有したのは整数セルの表面生成と、素材の質感を付ける処理。

## 見た目と構造

- セルはすべて15cm角。形を変える面取り、薄い別サイズの装飾メッシュは追加していない。
- 1階の緑の壁、2階の生成りの壁、青灰色の切妻屋根、煉瓦の煙突、3か所の窓の柵を対象固有に設計。
- 中央の窓枠と鎧戸はユーザーの既存方針に従って省略。ガラスは既存の不透明な色ガラス表現。
- 屋根と玄関庇は「瓦2セル＋色違い2セル＋継ぎ目1セル」を反復。継ぎ目も同じ高さで埋め、青灰色の控えめな色差で区切る。7段の勾配と閉じた下地を保つ。
- 木目は部材の方向に合わせる。細かな質感は離れると弱め、セルの輪郭や編集座標は変えない。
- 裏側・左側は参照に写っていないため推定。敷地の植栽・塀・街灯は別の対象として扱う。

## 検証と限界

基礎から全セルが面で接続すること、5か所の窓のガラスと開口、扉前の通路、庇の高さ、煙突の穴、窓の柵の接続を `check-model.mjs` で確認。描画用の面がセルの外周面と一致することも検査する。

元画像の面取りや自然な不揃いさを完全には再現していない。屋根は2026-09-24のユーザー指定でパン屋に近い粒度へ変更し、参照の微細な区切りより町全体でのまとまりを優先した。壁の補修色はやや広い。これは15cmの編集可能なセルによる近似モデルであり、元画像から抽出した3Dモデルではない。

通常表示は19,474セル、15,348三角形、22部品。前の5列配色は13,190三角形で、配色の境界が増えた分だけ描画面も増えた。セル数と描画負荷は同じではなく、隠れた面を除き、同じ属性の面をまとめている。iPhoneでの実測、地区全景、歩数に合わせた建築への統合は今回の範囲外。構造試作の確認と製品採用の判断は別。

画面操作があったときだけ描画し、影は光や部品位置が変わったときだけ更新する。暖機後の通常描画は地面を含め23回の描画呼び出し、15,350三角形。分解用の内部面は最初の分解時に生成して再利用する。検証後は45ジオメトリ（組み立て・分解の両方と地面）がGPUに残る。LODは未実装。端末上で必要なフレーム時間・メモリの上限は町全体と共に別途検証する。

`ボクセル保存` はパレットと工程タグを含むJSONを保存する。`voxel-document.mjs` の読み戻しで全セルと色が一致することを検査済み。UIでの一般作品の読み込み・歩数建築への接続はまだない。`runtime.test.mjs` は保存復元、分解時の閉じた表面、ブラウザーが出した部品階層を検査する。

## 記録の読み方

現行は `roof-pairs`（2026-09-24）。喫茶店roof16で承認された2＋2＋1の配色方法を適用し、継ぎ目は `#455f70`。屋根・庇の色以外は、下記roof-coarseとセル座標・部品・工程・非屋根色が完全一致。接地・窓・通路・煙突・柵・屋根の接合・描画境界・保存復元を確認。実ブラウザーの画像と最新描画量は `evidence/roof-pairs-*`。過去の工程画像は変更しない。

以前の `roof-coarse` は幅9セルを目安に5列（端は10セル）、奥行き3セルごとの7段。高低差3セルの段も下地を深くして面で接続する。新屋根が覆う妻壁上端32セルを屋根へ置き換え、それ以外の屋根以外のセルは同一。棟、窓の柵、煙突の開口も維持する。`evidence/roof-coarse-*.png` は当時の実ブラウザー画像、`roof-coarse-structure.json` は境界照合と上面・接合の検査。以前の工程画像は初版の履歴として保持。全工程の品質審査を再実施した記録ではない。

`evidence/` に各工程の実際の描画、比較、元の不合格診断と修正後の診断を残す。視覚スコアはエージェントによる近似度の判断であり、測定値やユーザーの承認ではない。

汎用の色検査は画像全体の5色から各部品の色を探すため、小さい煉瓦煙突を誤判定した。元の結果を残した上で、全ての遮蔽物を維持した部品ID描画から実際に見える画素を取り出し、同じ色差上限20で追加検査した。21部品が観測可能。内部の床は隠れているため色の一致を主張しない。追加検査でも形状の不合格は引き継ぐ。

`lighting` の失敗は地面に落ちる影を建物の幅に数えていたため。`lighting2` 以降は建物単体の画像で形状を測り、地面の影を含む画像を `context` として別に保存する。影を削除して見た目の合格を装うための処理ではない。

Pythonの工程スクリプトはローカルに導入された img2threejs を使用する。一般の閲覧には不要。仕様・記録を書き換える初期作成用 `author-spec.mjs` はレビューがある場合に停止する。

## 地区タイルの形について

正方形は必須ではない。長方形、角を落とした形、川岸に沿った輪郭を表現できる。ただし現在の地区配置・道路・水路の前提をそのまま変えられるという意味ではなく、形ごとの占有領域と接続位置を設計する必要がある。

自由建築との両立には、内部の配置基準は格子で持ち、見える地面だけ輪郭を変える方式が候補。接続する辺の幅、道路・水路の接続口、高さは共通化する。住宅のセルの大きさと、地区タイルの形は独立。今回はタイルの形を変更していない。
