# 個別制作の正本

全景の既存5棟は配置用の仮組み。ここでは各棟の切り出し画像を正本として、1棟ずつ独立して設計・実装・比較する。

1. `../references/crops/manifest.json` に元画像・切り出し矩形・ハッシュ・画素一致を記録する。
2. 対象の画像から輪郭、比率、開口、付属物、色の配置を観察し、対象固有の設計を書く。
3. 対象だけを実装し、同じ向き・大きさの参照と比較する。共通の建物テンプレートで別の棟を一括生成しない。
4. 正面側・側面・裏側、建築順、構造を確認し、差を記録して修正する。
5. その棟の検証が済んでから次へ進む。参照で見えない面は推定と記す。

共用するのは整数セル、外面メッシュ化、描画などの基盤。寸法、外形、開口、屋根、配色、店先の設計は棟ごとに持つ。

次の対象に着手する前に[ボクセル制作ノート](../../../VOXEL-PRODUCTION-NOTES.md)を参照する。喫茶店で有効だった方法を、対象の特徴と課題に合う場合だけ使う。
