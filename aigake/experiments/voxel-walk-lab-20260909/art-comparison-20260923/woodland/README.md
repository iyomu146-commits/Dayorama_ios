# 林間の町：原案からのボクセル再現

`index.html` は本体と独立した比較用の改良版（`?v=2`）。採用した `references/town-voxel-v2.png` を参照して、住宅・パン屋・本屋・花屋・喫茶店、樹木・植栽・家具・街灯・橋を15cm格子で組み立てた。本体の地区はまだ差し替えていない。

## 比較

- 全景と各棟を切り替える。「原案」は同一の元画像を `references/regions.json` の領域で切り出して表示する。別生成や描き直した画像ではない。PNGの個別画像は作らず、元画像と領域を正本にする。
- 「色の変化」でセルに持たせた壁・屋根・木・石・植生の色差を比較する。
- 光は昼・中立・低い光・夜。視点と露出を保って切り替える。窓の夜間発光はあるが、本体の生活演出や夜間の街灯照明はこの試作へ移植していない。
- 建物を単独表示すると0〜20,000歩の基礎→骨組み→壁・窓→屋根→店先を確認できる。全景の歩数は操作できない。本体の地区進捗・歩数保存とは別の造形検証用タイムライン。
- ドラッグ回転、ピンチ拡大、画角復帰。検証メニューに分解、描画PNG、ボクセルJSONの保存。JSONはこの試作の `dayorama-woodland` 形式で、現行エディターへの読み込みは未接続。

## 実装

`plan.mjs` は寸法・配置・95色のパレット・素材別の粗さ。`scene-model.mjs` は編集可能な整数セル。輪郭は実際の立方体、窓や家具も同じ格子。参照画像の貼り付けや細密な写真テクスチャは使わない。

セルを保存したまま、描画時は共通 `density-core.mjs` で隠れた面を除去して結合する。今回追加した外部パレット・素材別の粗さ・AO量の引数は、以前のデモの既定値を変えない。

建築順は工程ごとに既存支持から6近傍でたどる。施工中の木の骨組みは履歴に保持する。建築中も完成形の画角を維持する。

## 検証と残り

`node --test scene-model.test.mjs ../coarse-cafe.test.mjs ../density.test.mjs`：20件合格。全セルの整数座標・重複・パレット、建築順の各追加セルの接続、5棟の屋根被覆、中央の窓枠なし、入口クリア、描画値の有限性と既存デモへの回帰を確認した。木は建物セルを上書きすると生成時にエラーになり、枝葉がそれぞれの幹までつながることも検査する。

初稿で390×844、改良版で原案の並置、喫茶店の昼／中立／低い光／夜と裏側、6,000歩の骨組みを確認。改良版の確認時は実行エラー0、Windowsのシェーダーコンパイラによる微小値の丸め警告1件。iPhone実機の描画負荷は未測定。

**視覚品質の最終合格は未判定。** 改良内容と実際の描画は `evidence/refinement-v2.md` に記録。屋根の突起を幅のある瓦へ変更し、木を大きい葉の塊に再構成した。窓の横縞を除き、壁の色差と空の反射を調整した。原案との建物の比率・空間密度、花と店先の細部、樹種の違いは引き続き調整対象。

`evidence/blockout-review.md` に初期の不合格記録がある。背景を含む原画に単体物体用の画素検査を適用した結果は `evidence/intake.md` に制限を記録した。凸包のスコアは外周・大きさの診断であり、形や品質の合格に使わない。根拠が弱い段階で品質判定を `continue` に進める操作は自動承認レビューで拒否され、実行されていない。試作の設計状態はblockoutのまま、合格を装う記録は残さない。
