## 進める順序と完了条件

### 1. 自分のiPhoneで毎日使える状態にする

担当：実装・CI整備は開発側。Apple登録・契約・証明書・アカウント設定と実機操作は所有者。

- [ ] iPhone先行、対応OS・端末、最初の配信国と言語を確定する。現構成はiOS 16.4以上。最低対応端末は実測で決める。
- [ ] 表示名「こもれび」とプロジェクト名「Dayorama」の扱い、アイコン、識別子を統一する。既存の公開済み識別子がある場合は不用意に変更しない。
- [ ] 必要なソースをGitHubへ配置し、署名なしでアプリ本体＋Widgetのビルドを成功させる。
- [ ] Apple Developer登録、App ID、本体とWidgetのApp Group、配布用署名、App Store Connectのアプリ登録を確認する。
- [ ] 署名付きビルドをTestFlightへアップロードし、所有するiPhoneにインストールする。
- [ ] 実際に歩く→アプリを閉じる→再度開く→差分建築→記録→Widgetまで通す。

完了条件：ローカルサーバーなしで動き、実歩数が一度だけ建築へ反映され、再起動しても町が残る。まず数日連続で使用する。

2026年9月20日の確認では、App Store Connectへの提出はXcode 26以降・iOS 26 SDK以降でのビルドが必要。これはアプリの最低対応OSとは別の条件。現CIはXcode 26を選ぶ構成だが成功は未確認。[Appleの提出要件](https://developer.apple.com/news/upcoming-requirements/)

### 2. 本体と編集・保存をつなぐ

- [ ] 標準地域、特別地域、東京の4区画、各地域の建物数・完成条件をコンテンツ一覧で管理する。
- [ ] 本体の町を編集画面で開けるようにし、地域・設計・建築進捗・配置物の保存先を統一する。
- [ ] 編集した建物と受け取った設計図に、実歩数・施工順・完成履歴・タイムラプスを適用する。
- [ ] 完成後の変更・移動・増築で、既存の歩数を消費し直したり完成を重複計上したりしない規則を確定する。試作の増築5,000歩は本体への採用判断が必要。
- [ ] 建物に関連する基本小物の解放、特別小物の所持と配置を本体へ統合する。草花は歩行で1株ずつ増やす。
- [ ] 写真の保存・OS共有メニュー、設計図ファイルの受け取り・書き出しをiPhoneで使えるようにする。
- [ ] 設計図はデータとして読み込み、コードを実行しない。サイズ・個数・座標・ID・形式の上限と配置検査を設ける。
- [ ] 未所持の特別小物を標準品へ置換し、元の設計を保持する。無料ユーザーも受け取りでき、無料2地区の範囲で建築できる。
- [x] 完成した町の一覧・再訪画面を追加する。次の町へ進んでも星座観測と星座帳を残す。ホームの地区名から切り替え、建築先と閲覧先を分離（2026-09-22）。
- [ ] 保存形式と景観モデルにバージョンを付ける。seedだけに依存せず、更新後も既存の町・施工順・配置を再現できるようにする。
- [ ] 保存中断、容量不足、破損、アップデートから復旧できる保存方式を用意する。既存データの移行前に復旧可能なコピーを持つ。
- [ ] 機種変更・再インストールで町、所持品、設計図、星座帳を引き継ぐ経路を実装し、往復で検証する。

バックアップは「購入の復元」と別機能。StoreKitで購入を復元できても、育てた町や受領済み小物の履歴までは戻らない。生の歩数履歴とゲーム保存を分離し、健康データを安易にクラウド保存しない。設計図の共有には歩数・購入情報を含めない。

### 3. 無料・有料を実際の商品にする

2026-09-22の合意：最初の2地区を無料で完成でき、680円の買い切りで全機能を解放する。購入は初回から可能。初期販売にサブスクや機能別・地域別・小物別の商品は設けない。詳しくは [MONETIZATION.md](./MONETIZATION.md)。

- [x] 初期商品は680円の単一買い切り、無料は2地区、購入は初回から可能とする。
- [ ] 無料2地区目の選択範囲、標準／特別地域、基本／特別小物の正式な収録リストを決める。
- [ ] 無料の小物操作と有料編集の境界を決める。推奨：所持小物の基本配置・移動・回転は無料、建物の設計や大きな地形・町の編集を有料にする。小物を買っても配置できない状態を作らない。
- [ ] 詳細ダッシュボードの表示項目を決める。候補：月・年の推移、曜日別、期間比較、建築履歴との対応。基本の歩数取得・簡易記録は無料で提供する。
- [ ] StoreKitによる買い切り購入、購入状態の検証、復元を実装する。設定などから初回より購入できるようにする。
- [ ] 無料2地区の計数と3地区目開始時の購入導線を実装する。2地区完成後も簡易歩数記録・再訪・タイムラプスを利用でき、未使用の歩数は購入後に引き継ぐ。
- [ ] 建築途中で購入しても、町・歩数・施工予定・小物・履歴が変わらず、編集や詳細記録などだけが解放されることを検証する。
- [ ] 購入の保留・取消・返金・オフライン・再インストール・機種変更をテストする。未決定の返金時扱いを仕様化し、既存の町・設計データを失わせない。
- [ ] 入手した小物・設計図の履歴を保存し、復元できるようにする。
- [ ] 購入済みなら再購入を案内しない。価格はストアから取得した表示を使い、商品登録時に日本680円の設定を確認する。

購入前から「無料2地区・その後は680円の買い切り」と提供範囲が分かるようにする。将来の大型コンテンツや追加クラウドサービスの扱いは未決定であり、既存機能を後からサブスクへ移して再課金する計画はない。

### 4. 実機で品質を固める

推奨：まず所有者の実機、その後TestFlightで少人数に7〜14日使ってもらう。人数・期間は開発上の目安で、Appleの要件ではない。

| 分野 | 確認すること |

| 建築 | 19,999→20,000歩、複数棟をまとめて完成、町完成と余剰歩数、演出途中の終了・再起動、再視聴による重複なし |

| 立体表現 | 接地、屋根の穴、扉・庇、通路、椅子と人物、桟橋と水面、車両と線路。回転・地域・seedを変えて検品 |

完了条件：データ消失・二重加算・購入権利の誤判定・通常操作でのクラッシュを未解決のまま残さない。実機名、OS、ビルド番号、結果を記録する。

## 最初の公開から外してよい候補

これは提案であり、既存の合意を取り消すものではない。

- Android、iPad・Apple Watch専用アプリ。
- 有料の生成API、公開ギャラリー、ランキング、チャット。
- タイムラプスの動画ファイル書き出し。アプリ内再生と写真共有を先行する。
- Widgetのアプリ未起動時の自動追従。同期時刻が分かる現方式を先行する。
- 新しい地域・小物の追加制作。既存素材の統合と品質確認を先にする。

バックアップと購入復元は、この後回し候補に含めない。
