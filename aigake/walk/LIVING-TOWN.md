# Dayorama — 時刻と暮らしの演出

2026-09-21。歩いて町を育て、開くたびに少し違う日常が見える。世話や回収を義務にせず、景観の中に生活の手がかりを置く。

## 今回の実装

| 要素 | 表現・条件 |
| --- | --- |
| アプリ名 | ホーム画面、アプリ内、ウィジェット一覧をDayoramaに統一。既存の歩数・町・星座帳の保存先は維持 |
| 空 | コードで描く空のグラデーションと夜の小さな星。雲・太陽・月は表示しない。夕焼けは画面の上側を暖色にして、下側へ淡く落とす。画像生成や外部APIは使わない |
| 時刻 | 端末の現地時刻に連動。5〜7時半に明るく、16時半〜19時半に暮れる。太陽の天文計算や現実の天気との同期ではない |
| 照明 | 昼は日差し、夕方は暖色、夜は町が読める青い環境光。窓は部屋単位で点灯し、深夜は点灯する部屋を減らす |
| 窓 | ガラスと確認できるセルだけが発光。温室など大きなガラス面は弱く、小さな窓は暖かく。未完成の建物には灯りを出さない |
| 街灯 | 灯具の発光、地形に沿う光だまり、近くの物への控えめな照り返し。点光源は窓分を含め最大6灯、影用ライトは増やさない |
| 煙 | 設計図に登録した煙突だけから細く立ち上る。位置・向き・積雪後の高さを確認。パン屋は早朝〜昼、住宅は朝夕、雪国は暖房、サウナは夕方〜夜 |
| 洗濯物 | 住居・宿の横庭に物干しを置き、朝に干し、昼に揺れ、夕方に住民が取り込んで帰る。3枚を順に扱い、家ごとに時刻をずらす |
| 配置 | 建物、川、道、木の幹、動物の囲い、既存の仕事場を避ける。住居の入口と横庭を結べない敷地は見送る。雪の村では屋外干しをしない |
| デバッグ | 朝・昼・夕方・夜・深夜・端末時刻へ切替。物干しのある町では取り込み動作を拡大表示できる |

洗濯物の対象は住宅、農家、宿、山小屋、旅館。現在の標準seedでは港と運河に配置できる。牧草地・山・里山は敷地や既存の動線が競合するため、無理に置かず省略する。一般住居を森の構成に追加する場合も同じルールを使う。

## 場面の設計

### 住宅の一日

- 朝8時台：籠を持つ住人が入口から横庭へ。3枚を干して家へ戻る。戸口の段差は地面ではなく敷居・テラスの上面に足を合わせる。
- 昼：住人がいなくても、洗濯物の弱い揺れ、日なたの椅子、開いた窓が生活を伝える。布は上端を固定し、洗濯ばさみも一緒に動く。
- 16時42分〜17時24分ごろ：家ごとの開始時刻に取り込みに出る。往路→18秒の作業→復路。干しっぱなし・取った布の復活を繰り返さない。
- 日没後：物干しは空、部屋に灯り。21時以降は少しずつ消灯。すべての家が同じ時刻に一斉消灯しない。

現在の動作は出入り・運搬・腕を伸ばす所作・布の切替まで。扉の開閉、布を腕に移す連続動作、籠へ畳む動作は次の仕上げ対象。短い出来事を見逃しても報酬や建築に不利益はない。

### 次に作る日常の連続動作

| 建物・場所 | 前の状態 | 人の動作 | あとの痕跡 | 接地・経路の条件 |
| --- | --- | --- | --- | --- |
| パン屋 | 窯に火、煙が少し多い | トレーを店内から棚へ運ぶ | 朝はパンが並び、午後は数が減る | トレーは両手、商品は棚上。玄関は空ける |
| 喫茶店 | テラス席が空 | 店員がカップを置き、客が腰掛ける | カップが残り、後で店員が片付ける | 椅子の座面・膝・足の高さを別々に指定 |
| 花屋 | 店先の鉢 | 水やり→鉢の向きを少し変える | 土の色が少し濃くなる | 水は注ぎ口から鉢内へ。通行人にかけない |
| 本屋 | 店外ワゴンが未設置 | 開店時に押し出し、閉店時に収納 | 日中だけワゴンと小さな看板 | 車輪は地面を転がす。看板を道路へ置かない |
| 市場 | 店内の木箱 | 店員が1箱ずつ運ぶ | 開店中だけ商品の山 | 箱を手に追従させ、置いた後は地面に固定 |
| 港 | 係留された舟 | 荷物を桟橋へ運ぶ | 桟橋に小さな荷物、舟は波で揺れる | 舟・桟橋・陸の連続性。人が水面を歩かない |
| 農家・牧場 | 餌場が空 | 住人が餌を補充→動物が近づく | 羊やヤギが顔を下げる | 柵の入口経由。頭と餌槽の距離を確認 |
| 雪の家 | 薪置き場 | 薪を屋内へ運ぶ | 薪が1段減り、煙が立つ | 薪は抱えられる寸法。雪の上面を歩く |

上表は次段階の仕様。既存の接客・水やり・運搬・動物の動きはあるが、店内外を結ぶ一日の一連の動作への統合は未実装。

## 継続運用のルール

- 歩数は建築を進め、時刻は完成後の暮らしを変える。暮らしは報酬受取や世話の催促にしない。
- 起動時は今の状態を表示。閉じていた時間の家事をまとめて再生しない。時刻やタイムゾーンを変えても歩数・報酬は増えない。
- 季節や曜日の小さな違いを優先し、住民数と動作数を無制限に増やさない。最初は1画面に主役の動作1〜2件、残りは弱い揺れや灯り。
- 動きをオフにした場合、煙・布・住民の動きは停止。時刻に応じた明るさは維持する。将来は住民を戸口や作業の途中で止めず、安全な静止姿勢へ寄せる。
- 演出自体はローカル計算でAPI費用なし。基本の一日の営みは無料に含める。有料は地域固有の道具や生活の種類を増やす方向で、無料の町を静止画同然にはしない。
- ウィジェットは最後に保存した町の画像。今回の時間変化はアプリ内の描画であり、閉じた状態でウィジェット画像が連続変化するわけではない。WidgetKitの更新枠に合わせた朝夕の画像生成は別途設計する。

## 確認の基準

1. 未完成建築には住人・洗濯物・煙・窓明かりを出さない。
2. 光るのは灯具と窓だけ。壁、温室全体、積雪を光源に見せない。
3. 人は戸口から出て帰る。床・階段・地面の上面と足の接点を一致させる。
4. 物干しの支柱、ロープ、布、留め具の接続を保つ。道・水面・他人の作業場に置かない。
5. 煙は煙突の頂点から上がる。屋根の途中や何もない空間から出さない。
6. ブラウザで昼夜と取り込みを確認。iPhoneでは電池消費、温度、30fps維持、バックグラウンド復帰を実機確認する。
