# 無料・定額・買い切りの仕様

2026-09-20、ユーザー確認済みの方針。課金範囲の合意を記録する文書であり、購入処理や利用制限の実装完了を意味しない。

無料でも町を完成させ、歩いた記録と完成した風景を楽しめる。有料では編集の自由度、記録の分析、選べる地域と小物を広げる。

## 提供範囲

| 内容 | 無料 | 定額プラン | 買い切り |
|---|---|---|---|
| 簡易歩数記録 | 利用可能 | 利用可能 | 購入不要 |
| 詳細ダッシュボード | 対象外 | 利用可能 | 機能単体で購入 |
| 標準地域 | 利用可能 | 利用可能 | 購入不要 |
| 特別な地域 | 対象外 | 全対象地域を利用可能 | 地域単位で購入 |
| エディット機能 | 対象外 | 利用可能 | 機能単体で購入 |
| 編集された設計図の受け取り・建築 | 利用可能 | 利用可能 | エディット機能の購入不要 |
| 建物に関連する基本小物 | 建築に合わせて入手 | 同左 | 購入不要 |
| 特別な小物 | 対象外 | 定期配布で入手 | セット単位で購入 |
| 完成した町の保存・再訪、建築履歴 | 利用可能 | 利用可能 | 購入不要 |
| 完成後のタイムラプス（1棟・地区全体） | 利用可能 | 利用可能 | 購入不要 |
| 基本ウィジェット | 利用可能 | 利用可能 | 購入不要 |
| 町の写真保存・共有 | 利用可能 | 利用可能 | 購入不要 |
| 自作した設計図の配布 | 受け取りは可能 | エディット機能に含む | エディット機能に含む。配布に別料金を設けない |

定額は機能と対象コンテンツをまとめて提供する。買い切りは必要な機能・小物セット・地域を個別に取得する。同じ機能を買い切りで購入済みなら、定額の利用終了でその購入権利を失わない。

## 地域と小物

- 定額の「無制限」は、利用期間中に全対象の特別地域を何度でも開始できることを指す。
- 買い切りの地域も、購入した地域を何度でも遊べる。建築回数ごとの課金は行わない。
- 基本小物は建物の用途や生活を表すものとし、無料でも家具・照明・柵・草花を揃えられる。
- 特別小物は形・素材・組み合わせに特色のあるセットとする。巨大な装飾物やファンタジーの造形を差別化の中心にしない。
- 一度入手した小物は繰り返し配置できる。所持個数を消費する仕組みにしない。描画や配置の上限とは分けて扱う。
- 小物が使えるようになる時点と、町に現れる演出を分ける。植生は従来どおり歩行に応じて株・本単位で増える。
- 小物の組み立て・配置に生成APIを使わない。制作や配信の費用とは別に、配置ごとの生成API料金を発生させない。

## 定額の利用終了後

- 完成した町は保存・再訪でき、建築中の町はそのまま完成まで進められる。
- 入手済み・配置済みの小物は残す。町や歩数記録を削除・巻き戻ししない。
- 定額による特別地域の新規開始、特別小物の新規受け取り、エディットと詳細ダッシュボードの利用を停止する。買い切りで所持する範囲は引き続き利用できる。
- 編集データそのものは保持する。利用権がないことを理由に既存データを破棄しない。

## 設計図の受け取り

- 無料ユーザーも受け取り・建築できる。受け取り側にエディット機能の購入を要求しない。
- 特別地域や特別小物の利用権は、設計図の受け取りだけでは取得しない。
- 未所持の特別小物は標準小物への置き換えで建築できるようにする。元の設計は保持し、置き換え後も接地・重なり・入口と通路を検査する。
- 特別地域で建築を始める場合は、その地域の利用権が必要。
- 受け取るのは設計であり、送り手の歩数や完成進捗は引き継がない。
- 作者自身が完成させる前でも設計図を配布できる。

## まだ決めていない内容

- 定額の販売期間・価格、各買い切り商品の価格、配布頻度と初期収録数。
- 簡易歩数記録と詳細ダッシュボードの具体的な表示項目。
- エディット機能の内訳と、入手した小物を使う無料操作との境界。小物の所持権と編集機能の利用権は区別する。
- 複数の町の保存枠。完成した町の保管と、編集中の町の枠を区別し、枠数を決める。
- 標準地域／特別地域、基本小物／特別小物の具体的な収録一覧。
- 定額と買い切りの併用時の割引・重複購入の扱い。

現在の試作は購入状態による制限を実装していない。実装する際も、既存の町・小物・歩数記録を失わせない移行を行う。

2026-09-20：11地域それぞれ30個、計330個の特別小物を制作済み。基本小物44個とは別の利用区分・地域パックIDを持つ。試作では全種類を配置できる。購入・定額配布・所持台帳は未実装。星見の丘の完成後に88星座の観測ゲームを解放する。地区を完成した実績で解放し、次の町へ移っても遊べる。定額継続だけを理由に、完成済み地区の観測や星座帳を取り上げない。
