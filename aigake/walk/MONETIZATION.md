# 無料2地区・680円買い切りの仕様

2026-09-22、ユーザー確認済みの方針。初期販売は「最初の2地区無料＋680円の買い切りで全機能解放」とする。購入は初回から可能で、無料地区の完成を待つ必要はない。初期販売にサブスクリプションや機能別・小物別の個別商品は設けない。

この文書は提供範囲の合意であり、購入処理、無料枠の制限、公開ギャラリーの実装完了を意味しない。

## 提供範囲

| 内容 | 無料 | 完全版：680円の買い切り |
|---|---|---|
| 新しい地区の建築 | 最初の2地区分 | 地区数の制限なし |
| 2地区完成後の遊び | 継続して遊べる仕組みを提供。方式は検討中 | 全地域の建築・編集・共有作品を楽しめる |
| 簡易歩数記録 | 2地区完成後も継続 | 利用可能 |
| 詳細ダッシュボード | 対象外 | 解放 |
| 完成した町の保存・再訪、建築履歴 | 2地区完成後も利用可能 | 利用可能 |
| 完成後のタイムラプス（1棟・地区全体） | 利用可能 | 利用可能 |
| 基本ウィジェット、町の写真保存・共有 | 利用可能 | 利用可能 |
| 公開作品の閲覧・絞り込み・並べ替え・いいね | 利用可能 | 利用可能 |
| 他ユーザーが編集した設計図の入手 | 対象外 | 利用可能 |
| 入手した編集設計図の建築 | 対象外 | 解放済み地区で利用可能 |
| エディット機能 | 対象外 | 解放 |
| 自作設計図の公開・コード共有 | 対象外 | エディット機能に含む。配布ごとの課金なし |
| 建物に関連する基本小物 | 建築に合わせて入手 | 同左 |
| 収録済みの特別地域・特別小物 | 対象外 | 全て解放 |

公開一覧・アカウント・いいね・コード共有はこれから追加する機能。現在の設計図共有はファイルの書き出し／読み込みのみ。

## 無料地区と途中購入

- 「2地区」は地域の種類数ではなく、新しく建築する町2つ分を指す。最初は林間の町に固定する。2地区目の対象地域・選び方は別途確定する。
- 1棟20,000歩を維持する。5棟の地区を2つなら合計200,000歩。無料期間の日数制限は設けず、自分のペースで完成できる。
- 従来案では3地区目の新規開始に完全版の購入が必要としていた。今回「無料でも2地区完成後に続けて遊べること」を追加要件とし、同じ2種類の地域を繰り返すか、完成した2つの町の中で遊びを続けるかを検討する。無料の新規建築回数の最終的な制限は、継続方式と合わせて決める。
- 設定などから初回より購入できる。1地区目・2地区目の建築途中でも編集・詳細記録などを解放でき、完成まで購入を待たせない。
- 購入で現在の町、歩数、施工予定、既存の小物や履歴を初期化しない。進行中の町はそのまま続ける。
- 完全版は課金による利用制限を解除する。建物の完成に必要な歩数や、地区完成に連動する星座観測などのゲーム内条件は維持する。
- 2地区完成後も簡易歩数記録は継続する。新規建築を保留している間の歩数・完成時の余剰歩数は失わせず、購入後の次の町に引き継ぐ。無料上限到達だけを理由に台帳をリセットしない。
- 無料で遊べる範囲と680円買い切りで解放される内容を購入前から分かるようにする。2地区完成後にゲームそのものが終了する案内にしない。毎回の起動で購入画面を強制表示しない。

## 無料で継続して遊ぶ方式の検討案（未決定）

- A：無料の2種類の地域を繰り返し建築できる。完成した町はアルバムに残し、別の町として建築する。用意した標準設計の候補、色・植栽・配置などで変化を付ける。この案を採用する場合、「町2つまで無料」から「2種類の地域は繰り返し無料」に無料範囲を変更する。保存済みの町の強制リセットは行わない。
- B：2つの完成した町で園芸と収集を続ける。歩行で種・つぼみ・開花と進み、花の記録を集める。花壇は決まった場所・数に収め、植生を際限なく増やして建物や道を隠さない。休んでも町や花が失われる仕組みにしない。
- C：町の住民・店の小さな出来事を歩行で進める。花屋の新しい鉢、喫茶店の来客など、既存の町で短い生活の変化を見せる。大きなオブジェクトで景観を埋めず、連続ログインや期限付きノルマを要求しない。
- 推奨案はAを主な繰り返しの遊びにして、BまたはCを完成した町を訪れる理由として補助的に加える構成。上記は提案であり、ユーザーが継続方式を選ぶ前に無料上限やゲーム挙動を変更しない。
- 無料の繰り返しに使う標準設計と、完全版限定のユーザー編集設計図を区別する。歩数の加算先と持ち越し方法は継続方式の確定時に決め、同じ歩数の重複消費・二重加算を起こさない。

## 地域・小物と設計図

- 完全版は収録済みの全地域・全小物、編集、詳細記録、基本共有機能を含む。解放済み地域は何度でも建築でき、建築回数ごとの課金は行わない。
- 基本小物は建物の用途や生活を表すものとし、無料でも家具・照明・柵・草花を揃えられる。
- 特別小物は形・素材・組み合わせに特色のあるセットとする。巨大な装飾物やファンタジーの造形を差別化の中心にしない。
- 一度入手した小物は繰り返し配置でき、所持個数を消費しない。描画・配置上限や、歩行によって町に現れる時点は利用権と分ける。
- 小物の組み立て・配置に生成APIを使わず、配置ごとの生成API料金を発生させない。
- 他ユーザーの編集設計図の入手・建築は完全版に含める。公開一覧、限定コード、外部ファイルの読み込みのいずれも同じ利用権を確認し、別の入口で課金区分を回避できないようにする。自分の既存保存データの復元は設計図の新規入手と区別する。
- 受け取る際は対応形式・収録小物・座標・個数と接地・重なり・入口と通路を検査する。完全版は収録済み全小物を含むため、旧方針の「無料受取用に特別小物を標準品へ置換する」処理は初期提供の必須要件から外す。
- 設計図に作者の歩数や完成進捗を引き継がない。作者自身が完成させる前でも公開できる。
- 星座観測は対応地区の完成後に解放する。次の町へ移っても観測や星座帳を残す。

## 共有サービスと継続運営

- 作品一覧は建物名・完成画像・必要歩数を表示し、ジャンル等による絞り込みと、いいね順・新着順などの並べ替えを用意する。
- 公開作品の閲覧・絞り込み・並べ替え・いいねは無料。編集作品の入手・建築、制作・公開・コード共有は完全版に含める。680円購入後は作品の入手・配布ごとの追加料金を取らない。
- コードを知る人がアクセスする限定公開は、指定した受取人だけを認証する共有とは別の仕様。最初の提供範囲は別途確定する。
- 作品の容量・個数・投稿頻度には通常利用を妨げない上限を設け、数値と運用方法は実測後に決める。買い切りを理由に無制限のサーバー容量を約束しない。
- 入手した設計図と完成した町は端末にも保存し、鑑賞・建築を毎回の通信に依存させない。
- サーバー代と、投稿確認・通報・問い合わせ対応の作業費を分けて把握する。継続運営は買い切りの売上からまかない、将来分の運営資金も確保する。
- 現時点でサブスクリプションの発売は予定しない。将来、継続サービスを追加する場合も、買い切りで約束した機能を取り上げて再課金しない。

## まだ決めていない内容

- 無料2地区目の対象地域と選び方、初期収録の正式一覧。
- 無料2地区完成後の継続方式。Aなら無料は2種類の地域、B/Cなら無料は2つの町という区分にし、案を混在させない。
- 詳細ダッシュボードの表示項目、無料の小物配置操作と有料エディットの境界。
- 公開作品数・投稿頻度・容量上限、アカウントと公開管理、共有機能の初期公開範囲。
- 将来追加する大型コンテンツやクラウドサービスの扱い。将来の全追加内容まで永続的に無償と約束するかは未決定。
- 無料地区数の保存・復元、機種変更、オフライン、購入の保留・取消・返金時の扱い。購入前の既存データを失わせない移行方法。
- App Store Connectの商品ID・販売地域・各通貨の価格設定。日本で680円の買い切りを販売する方針とし、設定時に選択可能な価格を確認する。

## 実装状況

2026-09-23の創作方針：一部の作者がボクセルの形そのものを作り込み、他のユーザーがその作品を入手して建築する循環を重視する。あらかじめ用意した部品の組み合わせ編集は、その自由な造形の代替とは扱わない。グラフィック方式は[比較試作](../experiments/voxel-walk-lab-20260909/art-comparison-20260923/README.md)で評価中で、移行は未決定。料金・権利区分はこの比較によって変更しない。

現在の試作は購入状態による制限を実装していない。この仕様変更だけでデモに無料上限を適用したり、既存の町・小物・歩数記録を削除したりしない。StoreKitで購入・復元を実装し、動作を検証してから利用制限を有効にする。

11地域それぞれ30個、計330個の特別小物と基本小物44個を制作済み。地域パックIDはコンテンツの分類として維持するが、初期販売の個別商品を意味しない。購入・所持台帳、本体への編集統合、公開共有基盤は未実装。
